# 🔍 HERMES - Многофункциональный OSINT инструмент

**HERMES** — это консольное приложение на Python, предназначенное для сбора и анализа информации из открытых источников. Инструмент объединяет в себе функции поиска данных по цифровым следам, анализа сетевой инфраструктуры и базовые инструменты для аудита безопасности.

## ✨ Основные возможности
* 📱 **Поиск по номеру телефона:** Определение оператора и региона.
* 🌐 **Анализ IP-адресов:** Геолокация, провайдер (ISP), часовой пояс и ASN.
* ✉️ **Поиск по Gmail:** Проверка формата и поиск связанных Gravatar-профилей.
* 👥 **Поиск по ФИО:** Генерация возможных вариантов написания и поиск совпадений.
* 📑 **Государственные идентификаторы:** Проверка валидности ИНН и СНИЛС.
* 🚗 **Авто-OSINT:** Определение региона по государственному номеру РФ.
* 🛡️ **Сетевое сканирование:** Пинг-тест хостов и проверка открытых портов (21, 22, 80, 443 и др.).
* 📂 **Метаданные:** Базовый анализ информации о файлах.
